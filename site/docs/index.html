Utiliser l'application

Un essai type, en 4 étapes

  1. Configurer le véhicule — bouton GMPe : choisir V1000 direct, rapport global ou chaîne détaillée ; saisir les harmoniques cibles (ex. 7.4, 18, 22.2) et l'ordre à tracer (ex. H18).
  2. Mesurer en direct — mode LIVE : le spectrogramme défile, les ordres émergents sont étiquetés en continu. Le voyant GNSS (●/▲/✕) dit si la vitesse est exploitable ; sinon les KPI affichent --.
  3. Enregistrer & analyser — bouton d'enregistrement (30 s audio + télémétrie), puis rejeu depuis Audio (WAV) : la vitesse est relissée par RTS et le curseur suit la lecture.
  4. Rapport — mode Rapport Manuel : tracer un ordre à la main (tracé assisté), le valider, exporter PNG ou PDF avec cartouche de traçabilité.

Les réglages qui comptent

  • FFT 512 → 4096 — résolution fréquentielle contre cadence temporelle : Δf = 44100/N, Δt = N/2 / 44100. Le tableau « expert » du dialogue Réglages affiche les deux en direct.
  • Plage dynamique — min/max dB de la colormap ; le min reste ≥ 5 dB sous le max (contrainte imposée, pas décorative).
  • Seuils du détecteur — niveau d'émergence minimal et porte dBFS du détecteur d'harmoniques.
Limite d'emploi. Tant que la campagne de validation terrain n'a pas eu lieu, les constantes de l'estimateur GNSS et les seuils sont provisoires (marqués comme tels dans le code). Les résultats sont exploitables en essai exploratoire ; aucune revendication de précision ne doit dépasser la preuve collectée.
